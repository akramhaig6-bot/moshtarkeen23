# نظام إدارة المشتركين — Moshtarikeen Hub

لوحة تحكم إدارية متقدمة لإدارة المشتركين والأرباح، مبنية بـ React + TypeScript + Vite + Tailwind CSS + shadcn/ui.

## التشغيل محليًا

```bash
# تثبيت الاعتماديات
npm ci

# تشغيل خادم التطوير (المنفذ 8080)
npm run dev
```

ثم افتح: http://localhost:8080

> `npm start` يعمل أيضًا بنفس طريقة `npm run dev`، وهو الأمر الذي تعتمد عليه منصات المعاينة والاستضافة.

## الأوامر المتاحة

| الأمر | الوصف |
| --- | --- |
| `npm run dev` / `npm start` | تشغيل خادم التطوير على المنفذ 8080 |
| `npm run build` | بناء نسخة الإنتاج |
| `npm run preview` | معاينة نسخة الإنتاج |
| `npm run lint` | فحص الكود بـ ESLint |
| `npm test` | تشغيل الاختبارات |

## حل مشكلة 404 في المعاينة الحية

إذا ظهرت رسالة `404: NOT_FOUND` في المعاينة، فالسبب عادةً أن خادم التطوير غير مشغّل أو الاعتماديات غير مثبتة:

1. تأكد أن `node_modules` مثبتة: `npm ci`
2. شغّل الخادم قبل فتح المعاينة: `npm run dev`
3. الخادم يستمع على `0.0.0.0:8080` ويقبل جميع النطاقات (مُعد مسبقًا في `vite.config.ts`)

## البنية

- `src/pages` — صفحات التطبيق (الرئيسية، المعاينة، 404)
- `src/components` — المكونات (لوحة التحكم، الأنظمة المتقدمة، CMS... إلخ)
- `src/data` — البيانات الافتراضية والضامة
- `src/hooks` — الخطافات المخصصة
- `public` — ملفات ثابتة (الأيقونات و robots.txt)
