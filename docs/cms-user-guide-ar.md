## نظرة عامة

نظام **CMS** هو استوديو تصميم متكامل يمكّنك من تخصيص شكل ومحتوى **تطبيق العميل** لكل مشترك على حدة. كل مشترك يحصل على تطبيق مستقل بالكامل — بألوانه وشعاره وأقسامه ونصوصه.

### المفهوم الأساسي:

```
المشترك → إعدادات CMS مخصصة → تطبيق عميل فريد
```

### المبادئ:

| المبدأ | الشرح |
|--------|-------|
| **كل شيء اختياري** | كل قسم له مفتاح تشغيل/إيقاف (Toggle) |
| **كل مشترك مستقل** | تغييراتك على مشترك لا تؤثر على الآخرين |
| **معاينة مباشرة** | يمكنك فتح تجربة التطبيق المستقلة لمعاينة النتيجة |
| **28 قسم** | من هوية الشركة إلى العناصر الإضافية |

---

## كيف تصل إلى استوديو CMS

1. افتح **لوحة الإدارة** (Admin Panel)
2. اختر المشترك الذي تريد تخصيص تطبيقه
3. ستجد قسم **"استوديو تصميم تطبيق العميل — 28 قسم"** مع شارة **CMS**
4. ستظهر أمامك التبويبات الـ 28 في شريط أفقي

> 💡 **ملاحظة:** الاستوديو يظهر كشريط تبويبات (Tabs) يمكنك التنقل بينها بالضغط على أي تبويب.

### 1. الشركة 🏢

**الهدف:** تعريف هوية الشركة/العلامة التجارية التي تظهر في تطبيق العميل.

| الحقل | الوصف | مثال |
|-------|-------|------|
| **اسم الشركة** | الاسم الكامل | شركة الاستثمار الحديثة |
| **المختصر** | اسم مختصر يظهر في الشريط العلوي | س.ح |
| **الوصف** | وصف مختصر عن الشركة | شركة استثمار مرخصة... |
| **الموقع** | رابط الموقع الإلكتروني | https://example.com |
| **البريد** | البريد الإلكتروني | info@example.com |
| **الهاتف** | رقم الهاتف + زر تفعيل واتساب | 966501234567+ |
| **العنوان** | عنوان المقر | الرياض، المملكة العربية السعودية |
| **السجل التجاري** | رقم السجل | 1234567890 |

**الصور:**
- **الشعار (Logo):** ارفع صورة الشعار — تظهر في الشريط العلوي والتنقل
- **Favicon:** أيقونة المتصفح الصغيرة
- **صورة الغلاف (Cover):** تظهر أعلى الصفحة الرئيسية

**السوشيال ميديا:**
أضف روابط حسابات الشركة على: Instagram، Twitter/X، Telegram، TikTok، LinkedIn، Snapchat

### 2. الملف الشخصي 👤

**الهدف:** تخصيص بطاقة الملف الشخصي للعميل (المشترك) في أعلى تطبيقه.

| الإعداد | الخيارات | الشرح |
|--------|----------|-------|
| **صورة العميل** | رفع / تلقائي / إخفاء | `رفع` = ترفع صورة مخصصة · `تلقائي` = أول حرف من الاسم · `إخفاء` = بدون صورة |
| **شكل الصورة** | دائرية / مربعة / مستديرة | شكل إطار الصورة |
| **اسم العرض** | الأصلي / مستعار / إخفاء | `مستعار` = اسم مخصص بدلاً من الاسم الحقيقي |
| **اللقب** | نص حر | مثال: "مستثمر مميز" |
| **رقم العضوية** | نص حر | رقم تعريفي يظهر للعميل |
| **الشارة** | بدون / VIP / مميز / بلاتيني / مؤسس | شارة تظهر بجانب الاسم |
| **المستوى** | Bronze → Silver → Gold → Platinum → Diamond | مستوى العضوية |
| **الحالة** | نشط 🟢 / معلق 🟡 / موقوف 🔴 / جديد 🔵 | حالة المشترك |
| **الهاتف** | كامل / مخفي جزئياً / مخفي | كيف يظهر رقم الهاتف |
| **لون الاسم** | منتقي ألوان | لون نص اسم العميل |

**خيارات إضافية:**
- ✅ إظهار البلد
- ✅ تاريخ الانضمام
- نص تعريفي (Bio)
- خلفية البطاقة (لون / تدرج / صورة / شفافة)

### 3. الشريط العلوي 📱

**الهدف:** تخصيص الشريط (Header) الذي يظهر أعلى تطبيق العميل.

**التفعيل:** مفتاح On/Off — إذا أطفأته يختفي الشريط العلوي تماماً.

| الإعداد | الخيارات | الشرح |
|--------|----------|-------|
| **العنوان** | نص حر | النص الرئيسي في الشريط |
| **العنوان الفرعي** | نص حر | يظهر تحت العنوان |
| **لون الخلفية** | منتقي ألوان | لون خلفية الشريط |
| **لون النصوص** | منتقي ألوان | لون كل النصوص والأيقونات |
| **نوع الشعار** | شعار الشركة / أيقونة / نص / إخفاء | ما يظهر كشعار |
| **موقع الشعار** | يمين / يسار / وسط | مكان الشعار |
| **الشفافية** | معتم / شفاف / ضبابي (Blur) | مظهر الخلفية |
| **الظل** | بدون / خفيف / قوي | ظل أسفل الشريط |
| **الارتفاع** | صغير / متوسط / كبير | ارتفاع الشريط |

**عناصر قابلة للإظهار/الإخفاء:**
- ✅ الشعار
- ✅ اسم العميل
- ✅ أيقونة الإشعارات 🔔
- ✅ زر الوضع الداكن 🌙
- ✅ أيقونة البحث 🔍
- ✅ زر تغيير اللغة 🌐
- ✅ زر القائمة ☰
- ✅ ثابت (Sticky) — يبقى أعلى الصفحة عند التمرير
- ✅ مؤشر التقدم

**أزرار مخصصة:**
يمكنك إضافة أزرار إضافية بأيقونة + اسم + رابط + لون.

### 4. الشريط السفلي ⬇️

**الهدف:** شريط التنقل السفلي (Bottom Navigation) — مثل تطبيقات الجوال.

**التفعيل:** مفتاح On/Off

| الإعداد | الخيارات | الشرح |
|--------|----------|-------|
| **عدد الأزرار** | 3 / 4 / 5 | كم زر يظهر |
| **الشكل** | مسطح / بارز / دائري / زجاجي | مظهر الشريط |
| **الظل** | بدون / خفيف / قوي | |
| **الخلفية** | منتقي ألوان | لون خلفية الشريط |
| **إظهار على الديسكتوب** | On/Off | إخفاء على الشاشات الكبيرة |

**تخصيص كل زر:**

| الحقل | الشرح |
|-------|-------|
| **الأيقونة** | اختر من +20 أيقونة (home, wallet, profits, operations...) |
| **الاسم** | النص أسفل الأيقونة |
| **الإجراء** | الصفحة: الرئيسية / المحفظة / السحب / الأرباح / العمليات / الحساب / عروض / فتح القائمة |
| **اللون** | لون الأيقونة والنص |
| **شارة** | رقم صغير يظهر أعلى الأيقونة (مثل: 3 رسائل جديدة) |
| **★ مميز** | الزر المميز يظهر أكبر في المنتصف |
| **👁️ إظهار/إخفاء** | إخفاء الزر دون حذفه |

### 5. الشريط الجانبي 📌

**الهدف:** قائمة جانبية (Side Menu) تفتح بالضغط على زر القائمة.

**التفعيل:** مفتاح On/Off

| الإعداد | الخيارات | الشرح |
|--------|----------|-------|
| **الموقع** | يمين / يسار | من أي جهة تفتح القائمة |
| **السلوك** | ثابت / قابل للطي / بالضغط | كيف تعمل القائمة |
| **الحالة الافتراضية** | مفتوح / مغلق | عند فتح التطبيق |
| **العرض** | ضيق (أيقونات فقط) / عادي / واسع | عرض القائمة |
| **الظل** | بدون / خفيف / قوي | |

**رأس القائمة (Header):**
- ✅ صورة العميل
- ✅ الاسم
- ✅ الحالة
- ✅ رقم العضوية
- ✅ إعدادات سريعة

**عناصر القائمة:**
لكل عنصر يمكنك تحديد:
- الأيقونة + الاسم + الوصف الفرعي
- الإجراء (الرئيسية، المحفظة، الأرباح، العمليات، الحساب، الإعدادات، المستندات، العروض، الدعم الفني...)
- شارة رقمية + لون مخصص
- فاصل بعد العنصر (خط أفقي)

**تذييل القائمة (Footer):**
- ✅ زر الدعم الفني (رابط واتساب)
- ✅ زر الخروج
- رقم الإصدار
- حقوق النشر

### 7. النصوص المخصصة ✏️

**الهدف:** إضافة نصوص وعبارات مخصصة تظهر في أماكن مختلفة من التطبيق.

**لإضافة نص:** اضغط `+ إضافة`

| الحقل | الشرح |
|-------|-------|
| **العنوان** | عنوان النص (اختياري) |
| **النوع** | عادي / تنبيه / نجاح / خطر / معلومة |
| **المحتوى** | النص نفسه — يدعم المتغيرات! |
| **الموقع** | أعلى الصفحة / تحت الملخص / أسفل الصفحة / شاشة الاستعلام / بعد الاستعلام |
| **تاريخ الانتهاء** | يختفي النص بعد هذا التاريخ تلقائياً |
| **الأيقونة** | أيقونة تظهر بجانب النص |
| **لون الخلفية** | بدون أو لون مخصص |
| **الحدود** | بدون / حواف / إطار كامل |
| **الحجم** | صغير / متوسط / كبير |
| **المحاذاة** | يمين / يسار / وسط |
| **اللون** | لون النص |

**المتغيرات المدعومة:**
```
{الاسم}          → اسم المشترك
{الهاتف}         → رقم الهاتف
{الرصيد_الإجمالي} → الاشتراك + الأرباح
{مبلغ_الاشتراك}  → مبلغ الاشتراك
{الأرباح}        → إجمالي الأرباح
{الرسوم}         → رسوم النظام
{البنك}          → اسم البنك
{IBAN}           → رقم الآيبان
{المنصة}         → منصة الاستثمار
{تاريخ_الانضمام} → تاريخ الانضمام
{الحالة}         → حالة المشترك
{اليوم} / {الشهر} / {السنة}
{عدد_العمليات}   → عدد العمليات
{آخر_عملية}      → اسم آخر عملية
{نسبة_الربح}     → نسبة الربح المئوية
```

**مثال:**
```
مرحباً {الاسم}! أرباحك الحالية: {الأرباح} — نسبة الربح: {نسبة_الربح}
```

## نصائح وحيل

### 💡 ابدأ بقالب جاهز
بدلاً من البدء من الصفر، طبّق قالباً قريباً من ذوقك ثم عدّله.

### 💡 استخدم Toggle بحكمة
أطفئ أي قسم لا تحتاجه — التطبيق يصبح أنظف وأسرع.

### 💡 النصوص الذكية
استخدم المتغيرات مثل `{الاسم}` و`{الأرباح}` لجعل النصوص ديناميكية.

### 💡 التواريخ الذكية
- **النصوص:** حدد تاريخ انتهاء لتختفي تلقائياً
- **الأقسام:** حدد فترة ظهور (من → إلى)
- **البانرات:** حدد تاريخ انتهاء

### 💡 انسخ بين المشتركين
إذا صمّمت تطبيقاً جميلاً لمشترك، انسخه لآخرين بدل إعادة التصميم.

### 💡 القوالب المخصصة
احفظ تصميمك الناجح كقالب مخصص لاستخدامه مع مشتركين جدد.

### 💡 معاينة دائماً
افتح "تجربة تطبيق العميل" بعد كل تغيير كبير للتأكد من النتيجة.

### 💡 العناصر المخصصة
- **الأزرار المخصصة في الشريط العلوي:** أضف روابط خارجية
- **أزرار الأقسام:** أضف أزراراً بروابط في كل قسم
- **Sparkline في البطاقات:** أضف رسوماً صغيرة بأرقام مفصولة بفواصل

### 💡 الوضع الداكن
فعّل الوضع الداكن مع تبديل تلقائي ليحصل العميل على تجربة مريحة ليلاً.

### 💡 Swipe Navigation
فعّل "تصفح بالسحب" لتجربة جوال ممتازة — العميل يسحب يميناً/يساراً للتنقل بين الصفحات.
