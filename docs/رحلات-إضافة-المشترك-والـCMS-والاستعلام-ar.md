# 🧭 خريطة الرحلات الشاملة: إضافة المشترك + نظام CMS + نظام الاستعلام

> **وثيقة رحلات تفصيلية** — تصف ماذا يحدث **عند كل ضغطة زر**، ما الشاشة التي تظهر، ما الفروع التي تتفرّع عنها، ما المكوّنات المستخدمة في كل مشهد، سلوك كل مكوّن ومكوّناته الداخلية، وكيف تُحفظ البيانات في كل خطوة — من البداية إلى النهاية.
> **القاعدة:** وصف بالعربية، بدون أكواد، بتسلسل شجري يرافقك خطوة بخطوة.

---

## 🔑 كيف تقرأ هذه الوثيقة (المفتاح)

- **→** تعني «ماذا يظهر/يحدث عندما».
- المسطّرح داخل قائمة يعني أن ما تحته فرع من الفرع الذي فوقه.
- **زر [X]** تعني زرًّا حقيقيًّا في الواجهة.
- **[نافذة/حوار]** تعني نافذة منبثقة.
- **[مشهد]** تعني منطقة/بطاقة على شاشة حالية.
- **◇ = خيار** (قرار يتفرّع عنه أكثر من مسار).
- **الترقيم** (1، 1.1، 1.1.1) يوضّح عمق الفرع: الرئيسي ← الفرع ← فرع الفرع.

# 📕 الفصل 1 — هيكل التطبيق (شجرة الدخول)

```
فتح التطبيق
 │
 ├─ الشريط الجانبي (أزرار التنقل الرئيسية)
 │    ├─ [النظام الإداري]      → لوحة المعلومات
 │    ├─ [لوحة إدارة النظام]   → إعدادات النظام العامة
 │    ├─ [نظام الاستعلام عن الأرباح] → قناة الاستعلام (تُشرح في الفصل 4)
 │    ├─ [سجل العمليات]        → إدارة العمليات
 │    ├─ [إضافة مشترك]         → النموذج + CMS + القائمة (تُشرح في الفصلين 2 و3)
 │    ├─ [التقارير]            → تقارير
 │    ├─ [الإعدادات]           → إعدادات
 │    └─ [النظام المتقدم]      → أدوات متقدمة
 │
 ├─ الشريط العلوي (بحث سريع + التاريخ + عدد المشتركين + الوضع الليلي)
 └─ منطقة المحتوى (تتبدّل حسب الزر المختار)
```

> ⚠️ ستغطّي هذه الوثيقة بالتفصيل: **[إضافة مشترك]**، **[نظام الاستعلام عن الأرباح]**، و**نظام CMS** المدمج داخل إضافة المشترك. الباقي يُذكر اختصارًا عند الحاجة.

# 📗 الفصل 2 — رحلة «إضافة المشترك» كاملة

## 2.1 الوصول إلى القسم

```
→ تضغط [إضافة مشترك] في الشريط الجانبي
 → يظهر مشهد الرأس:
     ├─ العنوان = تسمية القسم (قابلة للتخصيص من لوحة إدارة النظام)
     ├─ تحته: «N مشترك مسجّل»
     └─ ثلاثة أزرار:
          ├─ [تحميل بيانات تجريبية]
          ├─ [تصدير CSV]
          └─ [إلغاء التعديل]  (يظهر فقط في وضع التعديل)
```

### 2.1.1 زر [تحميل بيانات تجريبية]

```
→ تضغط [تحميل بيانات تجريبية]
 → يفتح [حوار تأكيد]: «هل تريد إضافة بيانات تجريبية؟»
      ◇ [نعم، أضف البيانات] → يضيف مشترك «أكرم هيج» كاملًا:
           │    ├─ بيانات النموذج (اشتراك 15,000 USDT، أرباح 4,200، رسوم 150، آيبان، رقم حساب، محفظة، بنك الراجحي)
           │    ├─ 5 عمليات مربوطة باسمه
           │    └─ تصميم CMS كامل (كل الأقسام الـ 28)
           │    → يظهر إشعار نجاح «تمت إضافة المشترك التجريبي...»
           │    → يُغلق الحوار
           └─ [إلغاء] → يُغلق الحوار بلا تغيير
```

### 2.1.2 زر [تصدير CSV]

```
→ تضغط [تصدير CSV]
 → يُولَّد ملف نصي (أعمدة مفصولة بفواصل) يضم كل المشتركين:
      الاسم | الهاتف | الآيبان | مبلغ الاشتراك | الأرباح | الرسوم | الحالة | تاريخ الانضمام | البنك | العملة | المنصة
 → يبدأ تنزيل الملف تلقائيًا
 → يظهر إشعار «تم تصدير بيانات المشتركين»
```

## 2.2 الرحلة الأولى: «هوية وتجربة بوابة المشترك» (مكوّن SubscriberExperienceBuilder)

> هذا المكوّن **عام** (لا يخص مشتركًا واحدًا): يضبط هوية الواجهة التي تظهر فوق نتيجة الاستعلام. يظهر أعلى قسم إضافة المشترك.

```
→ يظهر [مشهد: هوية وتجربة بوابة المشترك]
 ├─ عنوان: «هوية وتجربة بوابة المشترك» + شارات [Frontend] [يحفظ تلقائيًا]
 ├─ حقل [اسم الشركة / المؤسسة]        → نص حر
 ├─ حقل [عنوان البوابة]               → نص حر
 ├─ زر [رفع الشعار] + زر حذف الشعار   → يرفع صورة كشعار وتُعرض مصغّرة
 ├─ حقل [النص الترحيبي]               → نص متعدد الأسطر
 │
 ├─ قسم [الأقسام المخصصة] (عدّاد N أقسام)
 │    ├─ لكل قسم: [اسم القسم] [الموضع ▾] [لون القسم] [ظاهر/مخفي] [حذف]
 │    │       الموضع ▾: أعلى نتيجة الاستعلام / بعد ملخص المشترك / أسفل نتيجة الاستعلام
 │    ├─ حقل [محتوى القسم]
 │    └─ زر [إضافة] ← يُنشئ قسمًا جديدًا (يجب أن يكون له اسم، وإلا يظهر تنبيه «اكتب اسم القسم أولاً»)
 │
 └─ قسم [الأزرار التفاعلية] (عدّاد N أزرار)
      ├─ لكل زر: [تسمية الزر] [الموضع ▾] [المدة (بالثواني)] [اللون ▾] [ظاهر/مخفي] [حذف]
      │       اللون ▾: أخضر / أزرق / ذهبي / بنفسجي
      ├─ [وصف قصير تحت الزر] و [النص الذي يظهر بعد الضغط]
      └─ زر [إضافة] ← يُنشئ زرًّا جديدًا (يجب أن يكون له تسمية، وإلا تنبيه)
```

**سلوك المكوّن ومكوّناته:** كل تغيير في هذه الحقول يُحفظ مباشرة في إعدادات النظام (يحفظ تلقائيًا). الأقسام والأزرار المُضافة تُعرض كبطاقات قابلة للطي، ولكل قسم بطاقة تميّزها إدخالاتها.

## 2.3 الرحلة الثانية: نموذج «بيانات المشترك الجديد»

> بعد الهوية، يظهر **بطاقة النموذج** الرئيسية بعنوان «بيانات المشترك الجديد» (أو «تعديل بيانات المشترك»). كل الحقول اختيارية.

```
→ يظهر [بطاقة النموذج] بشريط علوي ملوّن
```

### 2.3.1 مجموعة: الاسم + الهاتف

```
├─ حقل [اسم المشترك]  (مكوّن FField)
│     → إدخال نص حر للاسم الكامل
│
└─ حقل [رقم الهاتف مع بادئة الدولة] — مركّب من:
     ├─ زر البادئة (عرض علم الدولة + الرمز + سهم):
     │     → تضغط [زر البادئة ▾] ← يفتح [قائمة منسدلة للدول]
     │           ├─ شريط [بحث باسم الدولة أو الرمز...]
     │           ├─ قسم [⭐ الدول العربية المميزة] (تظهر أولًا)
     │           ├─ قسم [جميع الدول] (تصل إلى 60 دولة ثم «...وN دولة أخرى»)
     │           └─ ◇ تختار دولة → يُثبَّت علمها ورمزها وتُغلق القائمة، وتُحفظ آخر دولة مختارة
     ├─ حقل [أدخل الرقم]
     ├─ زر [👁 إظهار/إخفاء الهاتف]  → يبدّل هل يظهر الرقم في الاستعلام
     │      (عند الإخفاء يتحول للأحمر مع تلميح «مخفي في الاستعلام»)
     └─ زر [× مسح الرقم]
     → تحته سطر صغير: «سيظهر في الاستعلام» أو «مخفي في الاستعلام»
```

### 2.3.2 مجموعة: الآيبان + رقم الحساب

```
├─ حقل [رقم الآيبان (IBAN)]    (خط خاص)  + زر [👁 إظهار/إخفاء] + زر [× مسح]
└─ حقل [رقم الحساب البنكي]                  + زر [👁 إظهار/إخفاء] + زر [× مسح]
```

**ملاحظة سلوكية:** عند الضغط على «إضافة المشترك» لاحقًا، سيُنشئ النظام **نافذة تأكيد** لهذين الحقلين (انظر 2.7.1).

### 2.3.3 مجموعة: المبالغ والعملات

```
├─ حقل [مبلغ الاشتراك]
│     ├─ زر العملة [العملة ▾] ← يفتح قائمة (بحث في عملات العالم + العملات الرقمية)
│     │      لكل عملة: رمز + اسم + شعار + تصنيف (فiat/رقمية)
│     └─ حقل رقمي [0]
│
├─ حقل [الأرباح]  (نفس منطق العملة)
│
└─ حقل [رسوم النظام]  (نفس منطق العملة، بعرض أصغر)
```

**القاعدة التلقائية:** إذا جعلت المبلغ 0، يُمسح حقل العملة ورمزها عند الحفظ.

### 2.3.4 مجموعة: حساب النظام

```
└─ حقل [حساب النظام]
     ├─ زر [نوع الحساب ▾]: يدوي / آيدي محفظة / عنوان محفظة
     │     ◇ يدوي        → حقل قيمة نصية
     │     ◇ آيدي محفظة  → [زر نوع المحفظة ▾] (قائمة أنواع محافظ بشعارات) + حقل قيمة
     │     ◇ عنوان محفظة → [زر الشبكة ▾] (قائمة شبكات بلوكتشين بشعارات) + حقل قيمة
     └─ عند الحفظ: يُركَّب الحساب حسب النوع
```

### 2.3.5 مجموعة: تاريخ الانضمام

```
└─ حقل [تاريخ الانضمام] (اختيار تاريخ) + زر [× مسح]
     → تحته: «يظهر فقط إذا مملوء»
```

### 2.3.6 مجموعة: عنوان المحفظة (ثلاث خطوات)

```
└─ [عنوان المحفظة (ثلاث خطوات)] داخل صندوق مميّز بشريط تقدم (1→2→3)
     ├─ الخطوة 1 [المنصة]:
     │      [اختر المنصة ▾] ← قائمة منصات مقسّمة [🔷 كريبتو] و [📊 فوركس] مع شعارات
     │      → بعد الاختيار تنتقل تلقائيًا إلى الخطوة 2
     ├─ الخطوة 2 [العملة]:
     │      شبكة من العملات الرقمية (حتى 24)؛ → تختار عملة فتنتقل إلى الخطوة 3
     │      زر [تغيير] ← يعيدك للخطوة 1
     └─ الخطوة 3 [العنوان]:
            حقل [أدخل العنوان] (نمط يختلف حسب العملة: BTC/0x...)
            زر [×] ← يمسح ويعيد للخطوة 1
            زر [مسح كل الخطوات]
```

### 2.3.7 مجموعة: الحالة + البنك

```
├─ حقل [حالة المشترك] (قائمة منسدلة):
│      نشط / مشترك جديد / رسوم مستحقة / توزيع أرباح / معلق / موقوف
│
└─ حقل [البنك — بحث بالدولة أو البنك]:
     ◇ وضع القائمة (افتراضي):
     │    [اختر البنك ▾] ← يفتح [قائمة البنوك]:
     │         ├─ [بحث باسم الدولة أو البنك...]
     │         ├─ شرائح فلاتر دول (حتى 8) + صف أعلام الدول السريعة
     │         ├─ نتائج بكل بنك (الشعار + الاسم + الدولة + نوع البنك + رمز سويفت)
     │         └─ زر [+ أدخل اسم البنك يدويًا]
     ◇ وضع الإدخال اليدوي:
     │    [اكتب اسم البنك] + زر [قائمة] ← يعيد لوضع القائمة
     └─ عند اختيار بنك: تظهر رسالة «تم اختيار ...» ويُحفظ آخر بنك وآخر دولة
```

### 2.3.8 مجموعة: العملة الرئيسية + المنصة

```
├─ حقل [العملة الرئيسية (للتوافق)]:
│     [اختر العملة ▾] ← قائمة عملات العالم (بحث) + علامة ✓ للاختيار
│
└─ حقل [المنصة (شعارات حقيقية)]:
      [اختر المنصة ▾] ← قائمة منصات مقسّمة كريبتو/فوركس، مع شعار كل منصة ونوعها
```

### 2.3.9 مجموعة: ملاحظات + نص السحب

```
├─ حقل [ملاحظات (اختياري)]  → نص متعدد الأسطر يظهر في ناتج الاستعلام كبطاقة تنبيه
└─ حقل [نص السحب]            → النص الذي يظهر للمشترك بعد تأكيد سحب الأرباح
```

```
→ زر [إضافة عملية/+] 
 → يُوسَّع [صندوق إضافة عملية]:
      ├─ [نوع العملية ▾]: توزيع أرباح / اشتراك جديد / تنشيط النظام / سحب أرباح / تحويل

## 2.6 الرحلة الخامسة: أزرار الحفظ والمعاينة

```
→ شريط الأزرار أسفل النموذج:
     ├─ [إضافة المشترك]  (أو [حفظ التعديل] في وضع التعديل)
     ├─ [معاينة حية]
     └─ [إلغاء]  (وضع التعديل فقط)
```

### 2.6.1 زر [إضافة المشترك / حفظ التعديل] — آلة الحالات

```
→ تضغط [إضافة المشترك]
 → 1) فحص التكرار (الإضافة الجديدة فقط): ◇ يطابق هاتف/آيبان مشترك آخر؟
 │        نعم → يفتح [حوار تحذير التكرار]: «يوجد مشترك بنفس البيانات»
 │              ◇ [إضافة على أي حال] ← يتخطى ويُكمل
 │              ◇ [إلغاء] ← يتوقف
 │        لا → يُكمل مباشرة
 │
 → 2) تأكيد الآيبان: ◇ يوجد IBAN ولم يُؤكَّد؟ 
 │        نعم → يفتح [حوار «تأكيد حفظ رقم الآيبان؟»]
 │              ◇ [نعم، احفظ] ← يُعلّم للاحتفاظ به
 │              ◇ [لا، امسح] ← يمسح الآيبان ثم يُكمل
 │        لا → يُكمل
 │
 → 3) تأكيد رقم الحساب: ◇ يوجد رقم حساب غير مؤكَّد؟
 │        نعم → يفتح [حوار «تأكيد حفظ رقم الحساب؟»]
 │              ◇ [نعم] / ◇ [لا] (لا = يمسحه ثم يُكمل)
 │        لا → يُكمل
 │
 → 4) المعالجة الافتراضية:
 │      ├─ دمج الهاتف مع البادئة (مع تنظيف الرقم من البادئة) وحفظ البادئة+ISO
 │      ├─ مسح عملات المبالغ صفرية
 │      ├─ تجميع حساب النظام حسب النوع
 │      ├─ تجميع عنوان المحفظة (منصة|عملة|شبكة|عنوان)
 │      └─ لو تعديل وتغيّر الاسم → تحديث العمليات القديمة بالاسم الجديد
 │
 → 5) الحفظ:
 │      ◇ تعديل → يُحدَّث المشترك مع تصميمه الجديد
 │      ◇ إضافة → يُنشأ مشترك جديد (بمعرّف فريد) + يُرفَق به تصميم CMS
 → 6) إن كانت هناك عمليات مؤقتة تُحفظ كذلك (باسم المشترك)
 → 7) يعاد تصفير النموذج وحقول CMS والقوائم المنسدلة، وتُرفع كل الخطوات
 → 8) يظهر إشعار «تمت إضافة المشترك بنجاح» + علامة «تم الحفظ» خضراء (تختفي بعد 3 ثوانٍ)
```

### 2.6.2 زر [معاينة حية] — الطبقة العلوية

```
→ تضغط [معاينة حية]
 → تفتح [طبقة معاينة تغطي الشاشة]:
      ├─ شريط علوي: «المعاينة الحية» + شارة [تحديث تلقائي]
      ├─ أزرار حجم الجهاز: [جوال 375] [تابلت 768] [ديسكتوب 1280]
      ├─ زر [فتح في نافذة جديدة]  ← يفتح المعاينة في تبويب مستقل (/preview)
      └─ زر [× إغلاق]  ← يغلق المعاينة
 → الجسم: إطار (iframe) يعرض لتطبيق العميل قائمًا على بيانات النموذج حاليًا.
```

**سلوك «التحديث التلقائي»:** كل تغيير في النموذج أو CMS يُخزَّن لقطة مؤقتة، وتُعاد المعاينة تلقائيًا خلال ~0.5 ثانية. عند [فتح في نافذة جديدة] تُحفَظ اللقطة ثم تُفتح صفحة `/preview`.

> **رابط مهم:** المعاينة الحية و [`/preview`](#) تستخدمان نفسًا المكوّن الذي ينشئ تطبيق العميل (SubscriberDashboard)، أي ما تراه هنا هو ما سيراه العميل فعليًا.

 └─ بطاقة صغيرة: [العمليات المسجّلة]
      → تحته [بيانات المشترك] (شبكة بيانات، كل خانة مكوّن DataItem):
            الجوال (إن ظاهرًا) · الآيبان (إن ظاهرًا) · رقم الحساب (إن ظاهرًا) ·
            البنك · حساب النظام · العملة · المنصة · منصة المحفظة · دولة البنك
      → ◇ يوجد ملاحظات → بطاقة صفراء «ملاحظات إدارية»
```

### 4.3.1 الملخص المالي

```
→ [بطاقة الملخص المالي] (تظهر فقط إذا كانت هناك أرقام/محفظة)
     ├─ [مبلغ الاشتراك] (بطاقة زرقاء) بالعملة
     ├─ [الأرباح] (بطاقة تركوازية) بالعملة
     ├─ [رسوم النظام] (بطاقة صفراء) بالعملة
     └─ [المحفظة الرقمية] (بطاقة بنفسجية): العنوان مختصرًا + زر [عرض العنوان الكامل/إخفاء]
```

### 4.3.2 تجربة بوابة المشترك (SubscriberQueryExperience)

```
→ تظهر مباشرة بعد الملخص المالي:
     ├─ بطاقة ترحيب داكنة (اسم الشركة + شعار + العنوان الترحيبي + النص الذي يستبدل {name} باسم المشترك)
     ├─ أقسام (حسب الموضع): أعلى/بعد الملخص/أسفل
     └─ أزرار تفاعلية: لكل زر عند الضغط:
          → يعرض شريط تقدم «جارٍ تنفيذ الطلب… X%»
          → بعد الاكتمال يعرض «النص الذي يظهر بعد الضغط»
```

> هذه التجربة **عامة** (من إعدادات النظام)، وليست تصميم المشترك.

### 4.3.3 مُطلِق تطبيق العميل (CMS)

```
→ [بطاقة بنفسجية «تطبيق العميل — تجربة CMS مستقلة»] + شارة [منفصلة بالكامل] + زر [فتح التطبيق]
 → تضغط [فتح التطبيق] → تُفتح [تجربة CMS بملء الشاشة] (راجع 4.5)
```

### 4.3.4 سجل عمليات المشترك

```
→ [بطاقة «سجل عمليات المشترك»] + عدّاد العمليات
 → جدول (مرقّم): # · العملية · المبلغ · التاريخ · الحالة
 → ترقيم صفحات
```

### 4.3.5 خدمة سحب الأرباح — آلة الحالات

```
→ [بطاقة «خدمة سحب الأرباح»]
 ◇ الحالة [خاملة] → زر [سحب الأرباح]
      → تضغط ← [تأكيد]: «هل تريد تأكيد طلب السحب؟» + [تأكيد سحب الأرباح] / [رجوع]
      → [تأكيد] ← [معالجة] شريط تقدم 20 ثانية
      → [اكتمال] ← يعرض نص السحب (من إعداد المشترك) أو رسالة «لا يوجد نص سحب مُدخل»
```

### 4.3.6 الطباعة والتصدير (PrintMenu)

```
→ [زر: خيارات الطباعة والتصدير] ← يفتح [قائمة]:
     ├─ [طباعة PDF] → يُنشئ مستند PDF قابلًا للطباعة
     ├─ [تنزيل PNG] → يُنزّل صورة عالية الجودة للبيانات
     └─ [إنشاء فيديو استعلام] ← [نافذة جودة الفيديو]:
            ◇ 480p / 720p / 1080p
            → [إنشاء الفيديو] ← «جارٍ إنشاء الفيديو...» ثم ينزّل بصيغة WebM
```

### 4.3.7 سجل جميع العمليات

```
→ [بطاقة «سجل جميع العمليات»] تعرض جدولًا عامًا لكل العمليات في النظام.
```

## 4.4 رحلة «فتح التطبيق» (تجربة CMS المستقلة)

```
→ تضغط [فتح التطبيق]
 → [طبقة بملء الشاشة محمولة إلى body]: هوية مستقلة منفصلة عن واجهة الاستعلام
      ├─ شريط علوي [تطبيق العميل — تجربة مستقلة] + نص «يعرض حصريًا محتوى CMS الخاص بالمشترك»
      ├─ زر [إغلاق] (أو Esc) ← يغلق
      └─ جسم التطبيق = SubscriberDashboard (تطبيق العميل الكامل)
           ├─ Top Bar (حسب إعدادات الـ CMS)
           ├─ Side Bar (إن فُعّل) — تفتح من زر القائمة
           ├─ الصفحة الرئيسية (بطاقة الملف، البانرات، البطاقات المالية، الرسوم، العدادات،
           │      الجداول، الرسائل، التقويم، المعرض، المستندات، الفاتورة، الخريطة، الويدجتات،
           │      تفاصيل الحساب، فوتر الشركة)
           ├─ التنقل عبر Bottom Bar / القائمة / بالسحب
           └─ الصفحات الفرعية: الرئيسية · محفظة المستثمر · أرباحي · العمليات · السحب ·
                  حسابي · الإعدادات · المستندات · العروض · أقسام مستقلة (sec:...)
           └─ تفاعلات داخلية: وضع داكن، حاسبة أرباح، QR استعلام، سحب داخلي، Lightbox صور
```

## 4.5 رحلة صفحة `/preview` (المعاينة المستقلة)

```
→ تُفتح في تبويب مستقل (من زر «فتح في نافذة جديدة» أو تلقائيًا)
 → تقرأ اللقطة المؤقتة (المشترك الحالي + العمليات + CMS)
 ◇ لا توجد لقطة → تظهر رسالة «لا توجد معاينة محفوظة» + إرشاد
 ◇ توجد لقطة → يعرض نفس تطبيق العميل (SubscriberDashboard) بناءً على اللقطة
```

# 📒 الفصل 5 — كيف تُحفظ البيانات (خريطة الحفظ لكل زر)

| الإجراء | ماذا يُحفظ | أين |
|---------|-----------|-----|
| كتابة أي حقل في نموذج الإضافة | قيمة الحقل (موضعيًا) | حالة النموذج حيًّا |
| كل تغيير في «هوية وتجربة بوابة المشترك» | إعدادات تجربة بوابة المشترك | إعدادات النظام (إشعار «يحفظ تلقائيًا») |
| تغيير في استوديو CMS | تصميم المشترك (كائن CMS) | جزء من بيانات المشترك الحالية (قبل الحفظ النهائي) |
| تعديل حقل أثناء المعاينة الحية | لقطة مؤقتة (مشترك+عمليات+CMS) | المعاينة (sessionStorage) — تُحدَّث كل ~0.5 ثانية |
| زر [فتح في نافذة جديدة] | لقطة المعاينة | المعاينة ثم فتح `/preview` |
| إضافة عملية مؤقتة | العمليات المعلّقة | مصفوفة محليّة بالنموذج |
| [إضافة المشترك / حفظ التعديل] | المشترك (بما فيه CMS) | قائمة المشتركين |

| (نفس الضغطة) آخر بنك/دولة | آخر اختيارات | تفضيلات المتصفح |
| [تحميل بيانات تجريبية] | مشترك + عمليات + CMS كامل | قائمة المشتركين/العمليات |
| [تصدير CSV] | ملف تنزيل | لا يُحفظ، يُنزّل |
| [نسخ تصميم من مشترك] | يُعدّل تصميم CMS الحالي | جزء من بيانات المشترك |
| [حفظ قالب مخصص] | القالب المخصص | قوالب CMS المخصصة |
| قائمة المشتركين: [تعديل/حذف] | تعديل/حذف مشترك | قائمة المشتركين |

# 📖 الفصل 7 — الرحلة الأم (كل ضغطة زر من البداية للنهاية)

**المطلوب:** إضافة مشترك ثم العثور عليه في الاستعلام ثم فتح تطبيقه.

```
البداية
│
1) [إضافة مشترك] في الشريط الجانبي  → شاشة إضافة المشترك
│    ├─ أ) [خيار] أكتب اسم + هاتف (أختار الدولة) + آيبان + رقم حساب
│    ├─ ب) أملأ المبالغ (اشتراك/أرباح/رسوم) مع عملات
│    ├─ ج) أضبط حساب النظام + تاريخ الانضمام
│    ├─ د) أكمل عنوان المحفظة (3 خطوات)
│    ├─ هـ) أختار الحالة + البنك + العملة الرئيسية + المنصة
│    ├─ و) أكتب ملاحظات + نص السحب
│    ├─ ز) أضيف عمليتين (سجل عمليات مؤقت)
│    └─ ح) أفتح استوديو CMS وأصمم (قالب + ألوان + أقسام + …)
│
2) [معاينة حية]  → أرى تطبيق العميل (يُحدَّث تلقائيًا) → [إغلاق]
│
3) [إضافة المشترك]  → [حوار التكرار] (لا يوجد) → [تأكيد الآيبان] → [تأكيد الحساب]
│    → يُحفظ المشترك + عملياته + تصميمه → إشعار نجاح → تصفير النموذج
│    → يظهر في قائمة المشتركين
│
4) [نظام الاستعلام عن الأرباح]  → شاشة البحث
│    → أكتب الاسم → [استعلام الآن] → شريط تقدم → النتيجة:
│         بطاقة الملف + بيانات + ملخص مالي + تجربة بوابة المشترك
│         + مُطلِق التطبيق + سجل العمليات + خدمة السحب + الطباعة + سجل عام
│
5) [فتح التطبيق]  → تجربة CMS بملء الشاشة (تطبيق العميل) → أستكشف الأقسام
│
6) خدمة السحب  → [سحب الأرباح] → [تأكيد] → [معالجة] → [اكتمال] يظهر نص السحب
│
7) [خيارات الطباعة والتصدير]  → [طباعة PDF] أو [تنزيل PNG] أو [فيديو]
│
النهاية ✔
```

## 📌 خلاصة سريعة

- **كل ضغطة زر** في هذه المناطق تتحرك عبر حالة ← مشهد ← فرع، ويُعاد تشغيلها على نفس البيانات المحفوظة.
- البيانات تنتقل: **إدخال → (حفظ) → المشترك (به CMS) → (استعلام) → ملف/تطبيق**.
- الخصوصية (إظهار/إخفاء) والتأكيدات (آيبان/حساب/تكرار) هي **بوابات** تحكم شكل الحفظ والعرض.
- بوابتان منفصلتان: **بوابة المشترك (عامة)** و**تطبيق العميل (خاص بكل مشترك)**.
